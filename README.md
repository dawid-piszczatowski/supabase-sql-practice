# supabase-sql-practice

SQL exercises I'm working through on a free Supabase project, using a small billing-style dataset: customers, plans, subscriptions, invoices and payments. All data is fictional.

I work in customer support. I'm learning SQL so I can investigate billing and account questions directly, instead of only escalating them.

## Files

| File | What it does |
|---|---|
| `01_schema.sql` | Creates the tables and loads sample data |
| `02_queries.sql` | Questions a billing support agent asks: overdue invoices, failed payments, totals per customer, repeated failures, invoice discrepancies |

## How to run

1. Create a free project at supabase.com
2. Open the SQL Editor, paste `01_schema.sql` and run it
3. Run each query from `02_queries.sql` one at a time
